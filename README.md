# Lori's Taxi

Invoices and trip sheets for Lori's Taxi, as an app for her iPhone and computer.

Open the web address for this repository's GitHub Pages site, then:
- **iPhone:** in Safari, tap Share → Add to Home Screen.
- **Computer:** in Chrome or Edge, click the install icon in the address bar.

No customer information is stored here. It lives on her devices and in her own Google Sheet.
